# PortfolioPage

The full reference page — sticky terminal-prompt nav, an asymmetric About with a "$ whoami" console panel, a rail-style Experience timeline, a Certifications shelf with the Golden Jacket wink, a bento Projects grid, and the Footer — composed top to bottom. Same tokens as before (nothing in `tokens.json` changed for this pass); what changed is how the pieces are arranged, which is the point: a page built from generic stacked cards versus one with an actual point of view.

This is a reference composition, not a shippable file: copy the section markup and `bundle.css` classes into your own static page rather than exporting this file whole — your real content (name, roles, real cert codes, real projects) replaces the example text used here. Cut the Certifications section entirely if you'd rather not run the joke; nothing else on the page depends on it.
