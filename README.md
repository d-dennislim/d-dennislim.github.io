# Dennis Lim — AWS Solutions Architect

Source for my personal portfolio: **[d-dennislim.github.io](https://d-dennislim.github.io)**

I design and build cloud infrastructure on AWS. The site covers my experience,
selected projects and AWS certifications.

## Built with

- [Astro](https://astro.build): static output, no UI framework
- Plain CSS driven by design tokens, with light and dark modes
- Self-hosted IBM Plex fonts
- GitHub Actions + GitHub Pages for deployment

The page ships about 3 KB of JavaScript. It targets WCAG 2.2 AA and a
Lighthouse score of 95+ in every category.

## Run locally

```bash
npm ci
npm run dev
```
